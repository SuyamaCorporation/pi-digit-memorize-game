# Pi Digit Memorization Typing Game

## 概要
πの最初の200桁を表示し、入力フィールドに桁を順番に入力して正誤をリアルタイム色分けするタイピングゲーム。正解桁数のハイスコアをlocalStorageに保存する。

## 機能
- πの200桁の表示（入力済み=緑、現在位置=青ハイライト、未入力=グレー）
- リアルタイム正誤判定フィードバック
- 位置・正解数・エラー数・ハイスコアの表示
- ハイスコアのlocalStorage永続化
- 参照用π桁表示（トグル）
- リセット機能

## 使い方
数字キーを押してπの桁を順番に入力します。正解すると緑に、不正解だと赤エラーが表示されます。「Show Reference」で桁を参照できます（チートモード）。
